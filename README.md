# parijat-rust-refresher

A personal refresher for the Rust programming language and ecosystem.

## Diagnose

What concepts have I forgotten?

1. Do the quizzes in [The Rust Programming Language - Interactive Version][trpl-b].
2. Do the exercises related to **conversions**, **smart-pointers**, **clippy** and **macros** from [Rustlings][rustlings].

Can I write Rust code?

1. Do the exercises from [100 Exercises To Learn Rust][100-ex-rs].

## Learn

Depending on what you forgot:

1. Scan through [Rust Language Cheat Sheet][cheats-rs].
2. Read the relevant sections of [The Rust Programming Language - Interactive Version][trpl-b].

Need to go deeper?

1. [Effective Rust][effective-rs].
2. [Rust for Rustaceans][rust4].
3. [Asynchronous Programming in Rust][async-book].
4. [Tokio Tutorial][tokio-tut].

## Practice

Keep [cheats.rs][cheats-rs] and [docs.rs][docs-rs] open. Then:

1. Do the exercises in [100 Exercises To Learn Rust][100-ex-rs].
2. Build a Rust CLI program. [Command Line Applications in Rust][cli-rs].
3. Build a full-stack web service. [Zero To Production In Rust][zero-to-prod-rs].

## Catch Up

1. Skim [The Cargo Book][cargo-book].
2. Skim [The rustup book][rustup-book].
3. Skim [This Week in Rust][this-week].
